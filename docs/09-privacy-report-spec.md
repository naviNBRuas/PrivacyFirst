# 09. Privacy Report Specification (v1)

Generated by `report.PrivacyReport`. Formats: JSON (machine) and Markdown (human).

## Fields
| Field | Meaning |
|---|---|
| `report_version`, `tool_version`, `generated_utc`, `source` | Provenance (source = file name only) |
| `detector` | Detector name; includes "placeholder" when applicable |
| `policy` | Full policy config used |
| `lookahead_frames` | Buffer depth |
| `frames` | in/out counts |
| `tracks[]` | id, first/last frame, frames redacted, ghost frames, treatments histogram, minor-risk flag |
| `fallback_reasons` | Histogram: face_detected, low_confidence, ghost_track, minor_or_unknown_age, backfill |
| `scene_level_events` | detector_error, scene_too_dark_to_trust_detection |
| `backfilled_regions` | Regions added retroactively by lookahead |
| `minor_exception_used` | Whether a guardian exception was applied |
| `verification` | status, verifier name, frames scanned, residual frames, escalations, unresolved (blocked) |
| `metadata` | verified_clean, keys_removed, keys_remaining, GPS before/after, audio dropped |
| `swap` | Null unless face change enabled: replacer, stub flag, region-frames swapped, render-time demotions, demotions by reason, identity assignments, unvetted flag, replacer errors, recognizer names/thresholds/checks/failures |
| `tracks[].synthetic_identity_id`, `tracks[].swap_demotions` | Library id of the synthetic identity (not a real person) and per-track demotion reasons |
| `context_identifier_scan` | `not_run` or `run_v0_heuristic` |
| `context` | Null unless the scan ran: engine, languages, passes, config, frames scanned, scan failures (frames blocked), regions by kind, redacted vs flagged-only counts and region-frames, backfilled regions, reviewer escalations applied, plan summary, `recognised_text_stored: false`. Counts and enums only, never text |
| `warnings[]` | Placeholder detector/verifier, stub replacer, unvetted identity library, no recognizer verification, replacer errors, detector errors, failed verification, metadata failure, kept audio |
| `notice`, `residual_risk_statement` | Honest framing text |

## Verification status values
`not_run`, `passed`, `passed_after_escalation`, `failed_frames_blocked`.
A `passed` from a placeholder/scripted verifier is flagged in `warnings` as not meaningful.

## What the report must never contain
Faces, crops, thumbnails, embeddings, metadata values, GPS coordinates, device serials, file paths,
user identifiers.

## Compatibility
Additive changes keep `report_version`; renames/removals bump it.
